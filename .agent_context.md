# Lattice - Agent Context

Lattice is a Streamlit research workspace for General Chemistry II students and instructors.

- Entry point: app.py; workspace navigation and workflows: workspace_ui.py.
- Chemistry, validation, charts, and exports: pipeline.py; fitted model evaluation: modeling.py.
- Student CSV entry and instructor batch intake: submissions.py.
- Versioned project snapshots: projects.py; verified OIDC authorization: access.py.
- Appearance: design.py and .streamlit/config.toml (ivory, navy, and muted copper).
- Python 3.13; pinned runtime in requirements.txt; test environment in requirements.lock.
- Run python -m pytest -q and python tests/run_browser_checks.py for verification.
- Printable student/instructor guides are in output/pdf; tools/build_results_guides.py rebuilds
  them with ReportLab, which is an authoring dependency, not an app runtime requirement.

LATTICE_LOCAL_MODE enables local storage, not instructor access. The legacy environment
variable and existing .catalyst owner stores are supported to preserve saved work. New stores
use .lattice. Do not change project schema or experiment IDs for a presentation-only rename.
